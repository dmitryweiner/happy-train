# Замороженная копия legacy-движка

Копия `*.js` из корня репозитория на момент этапа 0 (FIXIN-PLAN.md). Не редактировать.

Нужна, чтобы после рефакторинга можно было:
- перегенерировать golden-снимки старого поведения (`yarn test:golden:update`);
- искать решения уровней солвером (`yarn solve:legacy`);
- сравнивать старый и новый движок на одних сценариях.
