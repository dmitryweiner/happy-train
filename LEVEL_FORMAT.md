# Формат уровня Happy Train (v2)

Уровень — JSON-файл `levels/NN.json`. Игра загружает все такие файлы по порядку имён. Структуру описывает схема [`levels/level.schema.json`](levels/level.schema.json), а всё, что схема проверить не может (стыковку рельсов, расстановку вагонов, объекты на путях), проверяет `yarn level validate`.

## Пример

```json
{
  "$schema": "./level.schema.json",
  "version": 2,
  "grid": [
    ["",   "ES", "EW", "EW", "EW", "SW", ""],
    ["",   "NS", "",   "",   "",   "NS", ""],
    ["",   "NE", "EW", "EW", "EW", "NW", ""]
  ],
  "semaphores": [{"at": [5, 1], "initial": "closed"}],
  "trains": [{"at": [3, 0], "heading": "E", "wagons": ["wagon1"]}],
  "station": [3, 2]
}
```

Полный пример — [`levels/examples/generated-01.json`](levels/examples/generated-01.json).

## Координаты

- `grid[y][x]`: `y` — строка сверху вниз, `x` — столбец слева направо, отсчёт с 0.
- Точки объектов записываются как `[x, y]`, то есть **сначала столбец**.
- Поле от 3×3 до 30×20 клеток, все строки одной длины. Обычный размер — 15×10.

## Клетки

Клетка — строка с соединениями её сторон: `N` (верх), `E` (право), `S` (низ), `W` (лево). Пара букв — путь, по которому поезд проходит клетку. Буквы в паре пишутся в порядке `N, E, S, W`.

| Токен | Что это | Как выглядит |
|---|---|---|
| `""` | пусто | |
| `"EW"` | прямая горизонтальная | `─` |
| `"NS"` | прямая вертикальная | `│` |
| `"ES"` | поворот право ↔ низ | `┌` |
| `"SW"` | поворот лево ↔ низ | `┐` |
| `"NE"` | поворот верх ↔ право | `└` |
| `"NW"` | поворот верх ↔ лево | `┘` |
| `"EW+NS"` | пересечение (поезда проходят прямо) | `┼` |
| `"EW+SW"`, `"NS+ES"`… | стрелка | см. ниже |

**Стрелка** — две пары с общей стороной, одна из них прямая: `"EW+SW"`, `"EW+ES"`, `"EW+NW"`, `"EW+NE"`, `"NS+ES"`, `"NS+SW"`, `"NS+NE"`, `"NS+NW"`. Прямая пара пишется первой.

- **Корень** — общая сторона. Например, у `"EW+SW"` это `W`.
- Поезд, въехавший **в корень**, едет по прямой ветке (`straight`) или по боковой (`diverging`), смотря как стоит стрелка.
- Поезд, въехавший **с любой ветки**, выезжает через корень независимо от положения стрелки.

Запрещено:
- две дуги с общим корнем (`"NE+NW"`): у стрелки должна быть прямая ветка;
- три пары в одной клетке;
- две пары без общей стороны, если это не пересечение `"EW+NS"`.

## Объекты

| Поле | Формат | Правила |
|---|---|---|
| `trains` | `[{"at": [x, y], "heading": "E", "wagons": ["wagon1", "wagon2"]}]` | `at` — клетка локомотива. `heading` — куда он едет, то есть сторона, через которую он выйдет из своей клетки. В клетке должен быть путь, выходящий на эту сторону. Вагоны перечисляются от локомотива к хвосту и **ставятся сами**, по одной клетке назад по пути (через стрелку — по её начальному положению). Части поездов не должны занимать одну клетку. |
| `station` | `[x, y]` | Клетка с путём. Победа — когда **локомотив въезжает** в эту клетку. |
| `semaphores` | `[{"at": [x, y], "initial": "open"}]` | Клетка с путём, но **не стрелка** (клик по такой клетке переключал бы стрелку). |
| `switches` | `[{"at": [x, y], "initial": "diverging"}]` | Необязательно. Стрелки, которых здесь нет, стоят `straight`. |

## Правила стыковки

- Если путь выходит из клетки на сторону `E`, у соседа справа должна быть сторона `W`, и так же для остальных сторон. Иначе это ошибка.
- Путь, уходящий за край поля, — **предупреждение**, не ошибка. Так делают ловушки: поезд, выехавший за край, сходит с рельс.
- Тупиков внутри поля нет: путь в пустую клетку — ошибка стыковки.

## Механика игры, которую надо учитывать

- Поезд стартует с места из центра своей клетки и разгоняется с ускорением 0.5 клетки/с² до 2 клеток/с (за 4 с). Из стартовой клетки он выезжает примерно через 1.4 с, на полной скорости проходит клетку за 0.5 с. Дуга поворота короче прямой (≈0.785 клетки).
- Закрытый семафор останавливает локомотив, **въехавший в клетку семафора** (с любой стороны). Торможение — 4 клетки/с², то есть со скорости 2 клетки/с поезд останавливается за полклетки. После открытия семафора поезд снова разгоняется.
- Стрелку нельзя переключить, пока в её клетке стоит часть поезда. Вагоны идут строго по следу локомотива, так что переключение стрелки после проезда локомотива состав не разрывает.
- Поезд разбивается, если въезжает в клетку, где нет пути с его стороны, выезжает за край поля или сближается с другой частью поезда (в том числе с собственным хвостом на тесной петле) ближе чем на полклетки.
- Игрок управляет только стрелками и семафорами. Хороший уровень: без действий игрока поезд не доезжает до станции, а решение требует хотя бы двух кликов.

## Цикл проверки

```bash
yarn level validate levels/08.json   # схема, стыковка, объекты; все ошибки сразу, с координатами
yarn level render levels/08.json     # ASCII-превью: удобно сверить с задуманным
yarn level solve levels/08.json      # прогон без кликов + поиск решения с минимумом кликов
```

`solve` отклоняет уровень, который выигрывается без кликов. Если решение находится за 1 клик, уровень скорее всего слишком простой.

## Частые ошибки

| Сообщение | Что не так | Что делать |
|---|---|---|
| `cell (1,0) "EW": exits E, but cell (2,0) "NS" has no W` | соседние клетки не стыкуются | поставить в (2,0) клетку со стороной `W`, например `"SW"` или `"EW"` |
| `trains[0] at (4,0) heading N: cell "EW" has no track leaving N` | локомотив смотрит туда, где нет пути | указать `heading` вдоль пути клетки |
| `trains[0]: not enough track behind the locomotive for 3 wagon(s)` | за локомотивом путь кончается раньше, чем вагоны | меньше вагонов или сдвинуть локомотив вперёд |
| `trains[1]: cell (3,0) is already taken by trains[0]` | поезда перекрываются | развести поезда |
| `semaphores[0] at (5,3): a semaphore cannot stand on a switch` | семафор на стрелке | перенести семафор на соседнюю клетку пути |
| `switch NE+NW has no straight branch` | две дуги из одной стороны | одну из пар заменить прямой |
| `cell (1,0) "WE" is not canonical, write "EW"` (warning) | буквы не в порядке `N, E, S, W` | переставить буквы |

## Шаблон задания для LLM

> Составь уровень игры Happy Train в формате v2 (описание — LEVEL_FORMAT.md). Поле 15×10. Один поезд с двумя вагонами. На пути к станции должны быть хотя бы одна стрелка и один семафор. Без действий игрока поезд не должен доехать до станции, решение — 2–4 клика. Верни только JSON.
>
> После ответа: `yarn level validate` → исправить ошибки по сообщениям → `yarn level render` → сверить с замыслом → `yarn level solve` → если решений нет или хватает одного клика, изменить уровень и повторить.

Так был сделан пример `levels/examples/generated-01.json`. Первая версия прошла проверку, но `solve` решил её за 1 клик: поезд и так проходил левую стрелку на каждом круге. Закрытый семафор на подходе к станции сделал решение двухкликовым.
